# Video Focus

Browser extension (Chrome, Brave, Edge) that hides everything except the video on regular YouTube video pages (not Shorts, home or search): no recommendations, comments or header. Black background, only the picture in focus.

- Turn on: click the Video Focus icon in the toolbar at the top of the browser (or press **Alt+Shift+F**) while watching a video. The icon turns dark and shows a small grey ON label while focus mode is on; it is bright when the mode is off.
- Turn off: double-click the video (the icon or **Alt+Shift+F** work too)
- No data collection, no network requests. See the [privacy policy](https://nikay99.github.io/video-focus-yt/).

## Download
The ready-to-install ZIP is on the [Releases page](https://github.com/nikay99/video-focus-yt/releases/latest).

## Install (developer mode)
Unzip the download first, then:
1. Open `chrome://extensions` (or `brave://extensions`), enable **Developer mode**.
2. Click **Load unpacked** and select this folder.
